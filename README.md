# Audio Guitar Tuner — обновления

Публичный источник APK и сведений об обновлениях Audio Guitar Tuner.

- [Стабильные выпуски](https://github.com/ant0n-56/AudioGuitarTuner-updates/releases/latest)
- [Все выпуски, включая беты](https://github.com/ant0n-56/AudioGuitarTuner-updates/releases)
- [Канал stable](channels/stable.json) и [канал beta](channels/beta.json)

Пока выпуски не опубликованы, `latest: null` означает отсутствие выпусков,
а не подтверждение актуальности установленной версии. Вход в GitHub для проверки
обновлений не нужен. Приложение обращается к небольшому статическому JSON, а не к API GitHub.

## Публикация для владельца

1. Подготовить проверенный подписанный APK и описание изменений.
2. Создать черновик Release с тегом `v<versionName>`, прикрепить один APK.
   Для беты поставить отметку Pre-release. Пакеты: stable —
   `com.andinem.audioguitartuner`, beta — `com.andinem.audioguitartuner.beta`.
3. Перед первой стабильной публикацией записать в `signers.json` SHA-256 сертификата
   реально распространяемой стабильной версии. Сейчас stable не настроен, чтобы
   случайно не принять APK с тестовой подписью. Beta привязана к текущему тестовому ключу.
4. Приложить необходимые исходники и лицензии распространяемых компонентов согласно
   их лицензиям; APK использует TarsosDSP под GPL v3. Этот репозиторий сам по себе
   не заменяет предоставление соответствующих исходников.
5. Опубликовать Release. Workflow автоматически прочитает package, versionCode и
   versionName из APK, проверит подпись, размер, ссылку и SHA-256, затем обновит JSON
   только нужного канала. Проверить успешное завершение Actions перед объявлением выпуска.

Одинаковый versionCode нельзя повторно использовать для другого APK. Версию канала
нельзя понизить. Изменение описания допускается без замены APK.
При ошибке сведения об обновлении остаются прежними. После исправления Release
запустить workflow вручную с его тегом; пустой тег запускает только тесты.
Удаление опубликованного APK не удаляет запись автоматически: сначала отозвать
запись канала вручную (`latest: null`), затем удалять файл.

GitHub может кэшировать raw JSON несколько минут. В приложение не встраиваются
GitHub-токены. SHA-256 записывается в JSON; текущий клиент передаёт скачивание браузеру,
а установку — Android, и сам скачанный файл не проверяет.

## Старые установки

Некоторые версии 3.4.0 доверяют только ссылкам старого репозитория.
Они требуют однократного ручного скачивания новой версии с этой страницы.
После перехода приложение использует новый канал автоматически.
